Solving Sudoku Using Graph Coloring

Each candidate is a node. Two candidates that can't both be true are joined by an edge. The edge is strong when exactly one of them must be true, and weak when at most one can be.

Assume one candidate is true and color the graph in two colors, true and false. A true node makes all its neighbors false. A false node makes its strong neighbors true. If two connected nodes end up both true, the initial assumption was false. Remove nodes that were falsely assumed to be true.

Press Play to solve the puzzle.
